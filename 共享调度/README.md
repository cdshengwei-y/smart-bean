# 日清夜跑共享调度区

本目录是调度者与执行者1、2、3、4之间的共享通信区。所有线程都使用绝对路径访问：

`/Users/jh-05/Documents/ChatGPT/日清夜跑执行者/共享调度`

## 文件约定

- `plan.md`：当天夜跑的唯一执行计划。每天18:00由计划提交任务生成或更新，飞书“输入材料”必须填写该文件路径和归档路径；18:15夜跑只执行该文件定义的目标。
- `产出/plan-YYYY-MM-DD.md`：当天`plan.md`的只读归档，用于次日09:30复盘追溯。
- `任务表.md`：唯一的任务状态总表，只由调度者维护。
- `命令.md`：调度者下发的当前命令和依赖关系。执行者开始工作前先读取。
- `回传/执行者1.md`、`回传/执行者2.md`、`回传/执行者3.md`、`回传/执行者4.md`：调度者根据各执行者会话中的最终答复统一落盘。
- `产出/`：调度者生成的报告、日志、草稿等文件。

## 状态值

只使用以下状态：`待领取`、`执行中`、`等待依赖`、`已完成`、`异常`、`阻塞`、`已取消`。

## 更新规则

1. 固定执行者任务只做只读审计，直接在各自任务会话中返回结果；不得修改项目、共享目录、回传文件或任务表。
2. 调度者负责下发任务、读取会话结果、写回传文件、更新任务表和生成产出。
3. 执行者不得发起任何文件写入、构建、安装、烧录或其他会触发审批的操作。需要这些操作时只给出命令、证据和建议，由调度者执行。
4. 若执行者出现 `waitingOnApproval`，调度者不要求用户批准；该执行结果作废，立即改发“只在会话回传”的只读任务，必要时由当前主任务内 subagent 接管。
5. 缺少输入、权限或调度者决策时，执行者在会话中报告 `等待依赖` 或 `阻塞`，不得猜测数据或宣称完成。
6. 发现夜跑异常时，会话回传必须包含：异常现象、证据、建议处理、是否需要负责人介入、处理结果。
7. 不得在会话或此目录写入密码、密钥、令牌、客户隐私或其他敏感信息。

## 固定时间

- 每天09:30：根据昨晚真实产出提交飞书复盘计划表。
- 每天18:00：生成`plan.md`并提交飞书日清夜跑表；“输入材料”不得填“无”。
- 每天18:15：调度者读取`plan.md`并开始夜跑执行。

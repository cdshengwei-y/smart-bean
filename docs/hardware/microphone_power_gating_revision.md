# 麦克风独立断电改版方案

日期：2026-08-11  
适用对象：XIAO ESP32S3 Sense + 当前自研录音扩展板的下一版 PCB。

## 1. 结论

若后续空载对照确认深睡耗电主要来自扩展板麦克风支路，下一版应给麦克风增加独立的高边负载开关；不能把麦克风直接并到现有 TF 的 `GPIO40 / SD_PWR_EN` 开关后面。

原因是录音时 TF 必须供电写卡，而深睡时两者都必须可靠断电。独立开关可分别控制，也便于再次测量和定位。

## 2. 板对板连接器的空闲情况

当前投产版网表中，CN1 已连接的引脚为：

| CN1 Pad | 当前网络 | 用途 |
| --- | --- | --- |
| 3、25、27、30 | GND | 地 |
| 5、7 | 3V3_IN | XIAO 3.3V 输入 |
| 19 | SD_PWR_EN / GPIO40 | TF 负载开关使能 |
| 21 | GPIO41 | PDM DATA |
| 22 | SD_MOSI / GPIO9 | TF MOSI |
| 23 | GPIO42 | PDM CLK |
| 24 | SD_MISO / GPIO8 | TF MISO |
| 26 | SD_SCK / GPIO7 | TF SCK |
| 28 | SD_CS / GPIO3 | TF CS |

因此当前扩展板侧未接出的 Pad 为：`1、2、4、6、8~18、20、29`。

当前 CN1 的 PCB 焊盘排布是“一排奇数、一排偶数”，官方 JA3 则是“一排 1~15、另一排 16~30”。它们不能按相同 Pad 号对应。按两块板实际焊盘坐标、现有已工作信号和官方 JA3 原理图反查，空闲普通 GPIO 为：

| CN1 Pad | 官方 JA3 Pin | XIAO GPIO | 当前状态 | 作为 MIC_PWR_EN |
| --- | --- | --- | --- | --- |
| 4 | 17 | GPIO18 | 未用 | 推荐 |
| 6 | 18 | GPIO17 | 未用 | 备选 |
| 8 | 19 | GPIO16 | 未用 | 备选 |
| 10 | 20 | GPIO15 | 未用 | 备选 |
| 12 | 21 | GPIO14 | 未用 | 备选 |
| 14 | 22 | GPIO13 | 未用 | 备选 |
| 16 | 23 | GPIO12 | 未用 | 备选 |
| 18 | 24 | GPIO11 | 未用 | 备选 |
| 20 | 25 | GPIO10 | 未用 | 备选 |
| 1 | 15 | GPIO21 / USER_LED | 未用但带板载 LED | 不推荐 |

本步骤不选择 CN1 Pad。先将 U2 的 ON 脚标为独立网络 `MIC_PWR_EN`，并只接 100k 下拉；完成电源模块后，再把 `MIC_PWR_EN` 接到最终确认的一个空闲 GPIO。`CN1 Pad2` 和 `Pad29` 是 VIN，`Pad9~17` 对应原摄像头信号或电源，不列为本次电源使能候选。

## 3. 推荐电路

沿用已验证的 `TPS22919DCKR`，新增一颗 U2，使其只给麦克风供电。

```text
3V3_IN ----+---- U2 IN
           |
           +---- C5 100nF ---- GND       （紧贴 U2 IN）

MIC_PWR_EN ------------ U2 ON
                          |
                          +---- R10 100k ---- GND

U2 OUT ---------------------- MIC_VDD_SW ---- MIC1 VDD
                                  |
                                  +---- C3 100nF ---- GND  （紧贴 MIC1）

U2 QOD ---- R11 100R ---- MIC_VDD_SW

MIC1 GND / SELECT ----------- GND           （SELECT 保持当前固定声道接法）
MIC1 CLK -------------------- CN1 Pad23 / GPIO42
MIC1 DATA ------------------- CN1 Pad21 / GPIO41
```

器件清单：

| 位号 | 建议器件 | 作用 |
| --- | --- | --- |
| U2 | TPS22919DCKR / C2149796 | 麦克风 3.3V 高边负载开关，和已验证 TF 开关同型号 |
| R10 | 100k | `MIC_PWR_EN` 在复位和深睡前未配置时强制关断 U2 |
| R11 | 100R | 按现有 TF 开关做法连接 QOD，关断后释放 MIC_VDD_SW 残压 |
| C5 | 100nF | U2 输入去耦，紧贴 IN/GND |
| C3 | 100nF | 保留为麦克风去耦，但网络从 `3V3_IN` 改为 `MIC_VDD_SW` |

不要在 `MIC_VDD_SW` 再接到 `3V3_IN`；不要将 C3 留在常供电轨，否则会绕过 U2。

## 4. 必须同步的固件约束

在最终选择空闲 GPIO 后，新增 `kMicPowerEnPin = <所选GPIO>`。上电录音前先释放 GPIO hold、拉高该 GPIO、等待麦克风数据手册要求的启动时间后再初始化 I2S；保守起见首版使用 10ms，录音功能和首板验证正常后再缩短。

进入深睡的顺序必须是：

1. 停止并卸载 I2S/PDM。
2. `GPIO42 / MIC_CLK` 配置为输出低电平并 hold。
3. `GPIO41 / MIC_DATA` 配置为无内部上拉下拉的输入。
4. `kMicPowerEnPin` 拉低，关闭 U2，并对该 GPIO 执行 deep-sleep hold。
5. 再调用 `esp_deep_sleep_start()`。

第 2 至 4 步不可颠倒：麦克风失电时若 CLK 为高、DATA 有内部上拉，可能通过信号脚反向供电，抵消断电效果。

## 5. PCB 与验收点

- U2、C5、R10、R11 放在麦克风附近，`MIC_VDD_SW` 不跨越 TF 或天线区域。
- 保留 `MIC_VDD_SW` 和 GND 的可测测试点；这是下一次仅用万用表也能确认麦克风是否真的断电的关键。
- `MIC_CLK` 与 `MIC_DATA` 保持现有走线，不在 DATA 上增加强上拉；如需预留，CLK 可放 0R 串联位，默认短接。
- 深睡时测 `MIC_VDD_SW-GND`，应接近 0V；唤醒录音时应接近 3.3V。
- 做一次“深睡 1 小时”和一次“录音写 TF 10 分钟”复测，与当前板比较电池电压变化。

## 6. 不采用的方案

- `MIC_VDD` 直接接现有 `VCC_SD_3V3`：能断电，但麦克风和 TF 被绑死，录音时无法独立管理，后续排障不方便。
- 仅停 I2S、拉低 CLK：当前固件已做到，但麦克风 VDD 仍为常供电，不能作为硬件低功耗保底。
- 直接用 GPIO 给麦克风供电：GPIO 不是电源轨，启动浪涌、压降和可靠性均不合格。
